## 🛠️ Troubleshooting

### Common Issues and Solutions

**LEDs not lighting up**: Check the USB connection. Unplug and replug the LED controller. Restart GabeCubeAura.

**Colors appear wrong**: Open Display Settings in GabeCubeAura and recalibrate the color mapping.

**Application won't start**: Make sure you have the latest version. Right-click the icon and select "Run as Administrator."

**Performance drops**: Lower the screen sampling rate in the Video Settings tab. This reduces CPU usage.
